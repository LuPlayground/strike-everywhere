Concept · wallet integration
Concept · Wallet-native perps

A Perpetuals tab inside the wallet people already use.

On Hyperliquid, wallets that embed trading became the biggest source of builder volume. This is what that looks like for Cardano: a wallet adds one component, and its users trade Strike perps without leaving the wallet.

  • 1No new site, no new seed. The wallet's own keys sign Strike's one-time connect message.
  • 2The wallet earns. Its builder code collects a small fee on every fill, credited by Strike.
  • 3Safe by design. The trading key can't withdraw; deposits are checked before signing.
Concept"Halo" is a fictional wallet for illustration. Real wallet integrations (Lace, Eternl, Vespr, …) would be partnerships.
