Questions

    
Do I need a backend or API keys?
No. The panel talks directly to Strike from the user's browser. Your only credential is your public builder code.

    
Can my app access user funds?
No. The trading key created at connect can place orders but cannot withdraw: withdrawals need the user's own wallet signature and only go back to their wallet. Deposits are checked before the user signs.

    
What should I charge?
We recommend 5 bps (0.05%). Strike allows up to 100 bps, but the panel shows every fee before confirming. Low fees win volume, like Phantom at 5 bps on Hyperliquid.

    
Does it work in a wallet extension or mobile wallet?
Yes, it's a standard web component. In an extension popup set width="368"; if your CSP blocks remote scripts, bundle the ESM build (strike-everywhere.js) instead.
