Strike perps, anywhere Cardano lives.

One HTML tag puts a Strike trade ticket inside any wallet, dApp or community site. Users connect the wallet they already have with one signature; the host earns Strike builder fees on every fill, and a dashboard shows exactly what each site brought in.

How it works

  
Built entirely on Strike's own Builder Connect API. The widget calls Strike directly from the user's browser; no server holds trading keys.

  

    
EmbedAdd the script and a <strike-trade> tag with your Strike builder code.

    
ConnectUsers pick their CIP-30 wallet (Lace, Eternl, …) and sign once. Strike creates the account and a trading key that cannot withdraw.

    
Deposit & tradeADA deposits are built by Strike, checked in the widget, signed in the wallet. Orders carry your builder fee.

    
Get paidStrike credits builder fees on every fill. The dashboard verifies volume against Strike's public fill history.
